## N_Reynas: Búsqueda Tabú para el problema de las 8 reinas

Resuelve el problema de colocar 8 reinas en un tablero de 8 × 8 sin que se ataquen, usando **Búsqueda Tabú con memoria a corto plazo**, partiendo de un estado inicial aleatorio y midiendo tiempo y cantidad de movimientos.
